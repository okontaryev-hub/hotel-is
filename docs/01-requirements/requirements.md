# Специфікація вимог до ІС управління готелем

## Функціональні вимоги (FR)
* **FR-01 (Пошук номерів):** Система повинна дозволяти пошук вільних номерів за датами заселення, виселення та кількістю гостей.
* **FR-02 (Створення бронювання):** Система повинна реєструвати бронювання із зазначенням даних гостя та обраного номера.
* **FR-03 (Реєстрація заїзду Check-in):** Система повинна змінювати статус номера на "Зайнятий" та фіксувати час заїзду.
* **FR-04 (Реєстрація виїзду Check-out):** Система повинна розраховувати підсумковий рахунок за проживання та послуги.
* **FR-05 (Облік додаткових послуг):** Система повинна дозволяти додавати до рахунку проживання послуги (сніданок, SPA, паркінг).
* **FR-06 (Скасування бронювання):** Система повинна підтримувати скасування бронювання зі зміною статусу номера на "Вільний".

## Нефункціональні вимоги (NFR)
* **NFR-01 (Продуктивність):** Час відгуку системи при пошуку вільних номерів не повинен перевищувати 2 секунд.
* **NFR-02 (Безпека):** Персональні дані гостей повинні зберігатися у зашифрованому вигляді відповідно до GDPR.
* **NFR-03 (Доступність):** Система повинна бути доступною для користувачів 99.9% часу (24/7).
