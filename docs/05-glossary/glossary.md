# Глосарій термінів предметної області

* **Гість (Guest):** Фізична особа, яка користується послугами тимчасового проживання в готелі.
* **Номерний фонд (Room Inventory):** Сукупність усіх номерів готелю, доступних для бронювання.
* **Бронювання (Booking):** Попереднє замовлення номера на певний період із фіксацією дат заїзду та виїзду.
* **Check-in (Заселення):** Процедура офіційного оформлення проживання гостя та видачі ключів від номера.
* **Check-out (Виселення):** Процедура завершення проживання, перевірки стану номера та повного фінансового розрахунку.
